## &nbsp;About Me

I'm a **Software Engineer & AI Automation Architect** based in Faisalabad, Pakistan — currently at **FAST-NUCES**, building systems at the intersection of intelligent automation and scalable full-stack engineering.

I don't just write features — I **architect production systems** that solve real problems. Every project I ship is publicly deployed, documented to professional standards, and built with recruiter-grade code quality.

- ⚡ **Full-Stack Engineering** — Next.js 15 + React 19 + Node.js + MongoDB, deployed to production on Vercel
- 🧠 **Data Science & ML** — Python pipelines, LLM-powered automation, scikit-learn, Pandas, Jupyter

**Open to:** Full-Stack & AI/Automation roles · Remote positions · Product-led internships
