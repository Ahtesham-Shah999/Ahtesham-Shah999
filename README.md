## About Me

I am a **Software Engineer and Full-Stack Developer** with a strong emphasis on applied AI, automation architecture, and production-grade web engineering. Currently pursuing my degree at **FAST National University, Faisalabad**, I build systems that sit at the intersection of intelligent automation and scalable software — from n8n-powered AI agent pipelines to full-stack SaaS platforms deployed at scale.

My engineering philosophy centers on **product thinking with engineering precision** — I do not just build features, I architect systems that solve real problems with measurable impact. Every project I ship is production-deployed, documented to professional standards, and built with recruiter-ready code quality.

My core competencies span **three technical pillars**:

- **AI Agent Engineering** — Designing and deploying autonomous agent workflows using n8n, LangChain, and OpenAI APIs. I build agents that are grounded in structured knowledge bases, maintain conversational state, and integrate with real-world business surfaces.
- **Full-Stack Product Engineering** — End-to-end delivery of web applications using Next.js 15, React 19, Node.js, Express, and MongoDB — from architecture to Vercel/cloud deployment.
- **Data Science & ML** — Python-based ML pipelines, LLM-powered annotation automation, and data engineering using Pandas, scikit-learn, and Jupyter.

**Open To:** Full-Stack Engineering roles · AI/Automation Engineering · Remote-friendly positions · Internships at product-led companies

<summary><b>Stratify — AI-Powered Forex Strategy SaaS Platform</b></summary>
<br/>

An end-to-end SaaS platform that democratizes algorithmic forex trading by allowing non-technical traders to define, backtest, and automate trading strategies through a conversational AI interface — no code required.

| Attribute | Details |

| **AI Layer** | OpenAI GPT-4o · LangChain · Custom strategy DSL interpreter |
| **Scale** | Multi-user SaaS · Async backtest queue · Real-time market data ingestion |
| **Performance** | Sub-200ms strategy parse · Concurrent backtest execution via worker threads |
| **Security** | JWT auth · Rate limiting · Sandboxed strategy execution environment |
| **Repository** | [Stratify-Ultimate-AI-Powered-Saas](https://github.com/Ahtesham-Shah999/Stratify-Ultimate-AI-Powered-Saas) |

Stratify bridges the gap between retail traders and institutional-grade tooling. Users describe trading logic in natural language, the AI engine translates it into executable strategy parameters, and the backtest system runs historical simulations against live market data — all through a modern, dark-mode dashboard engineered for production readiness.

</details>

<details>
<summary><b>Zeytin — AI-Powered Restaurant Website with n8n Booking Agent</b></summary>
<br/>

A production-grade static restaurant website with an embedded conversational AI booking agent — demonstrating how to connect a vanilla JavaScript frontend to an n8n AI workflow via webhook, achieving stateful multi-turn reservation experiences without a backend server.

| Attribute | Details |
|---|---|
| **Stack** | HTML5 · Vanilla CSS (custom design system) · Vanilla JavaScript (ES6+) |
| **AI Layer** | n8n Chat Trigger · OpenAI GPT-4o · JSON knowledge base grounding |
| **Architecture** | Static frontend + n8n webhook · Session persistence via localStorage |
| **Performance** | Zero-dependency widget · Self-injecting IIFE · Sub-50ms widget load |
| **Security** | DEMO_MODE flag · Graceful error fallback · No credentials in client code |
| **Repository** | [Zeytin-site](https://github.com/Ahtesham-Shah999/Zeytin-site) |

The `restaurant-data.json` file acts as a single source of truth — grounding both the website content and the AI agent's knowledge base. The custom chat widget exposes a global `window.openZeytinChat(prefill)` API, enabling deep-link integration from reservation prompts directly into the agent conversation.

</details>
